# 📅 本周菜单 (2026-W37)

---

## 🍱 预定菜品

```dataview
TABLE WITHOUT ID rows.file.link[0] AS "菜品"
WHERE contains(this.recipes, file.name) and contains(file.folder, "菜谱库")
GROUP BY file.name
```

---

## 🛒 本周自动采购清单 (按超市区域汇总)

```dataview
TABLE WITHOUT ID
  ing.category AS "超市区域",
  ing.name AS "食材",
  string(ing.amount) + " " + ing.unit AS "用量"
WHERE contains(this.recipes, file.name) and contains(file.folder, "菜谱库")
FLATTEN main_ingredients + side_ingredients + seasonings AS ing
WHERE ing.category
SORT ing.category ASC
```
